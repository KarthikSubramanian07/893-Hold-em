# Contact

893 Hold'em is made by Karthik Subramanian and developed in the open on GitHub. The best way to reach the maker is there, where every report is public and nothing gets lost in an inbox.

## Report a bug or suggest a change

Open an issue at [github.com/KarthikSubramanian07/893-Hold-em/issues](https://github.com/KarthikSubramanian07/893-Hold-em/issues). It helps to include:

- what you expected and what happened instead;
- your device and browser (for example "iPhone 15, Safari" or "Windows, Chrome");
- the table code from the top-left corner, if it happened during a night.

Pull requests are welcome. The code is MIT licensed, and the repository's README explains how to run the game locally and how the pieces fit together.

## Privacy and security questions

For questions about data, see the [privacy page](https://holdem893.pages.dev/privacy) first. To report a security problem, use GitHub's private vulnerability reporting on the repository (Security tab, "Report a vulnerability") rather than a public issue, so it can be fixed before it is discussed.
