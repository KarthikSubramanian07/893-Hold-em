# A table at 893 Hold'em

This address is part of the live game: a table, the practice room, or the matchbook of collected stamps. It is played by people in a web browser with JavaScript and WebGL; there is no text version of a table in progress and no API to play through.

- To join this table, open the same address in a browser. Anyone with a table's link sits down at that table.
- To start a new one, open the [front page](https://holdem893.pages.dev/) and choose "Open a table".
- To learn how it plays, read the [rules](https://holdem893.pages.dev/rules.md).
- A summary for agents is at [/llms.txt](https://holdem893.pages.dev/llms.txt).
